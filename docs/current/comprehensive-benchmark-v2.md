# SheetPilot 真实 Excel 测试集 V2

## 目标

V2 不按原子能力拆成大量单步题，而是从用户任务出发，让一个工作簿同时承载：

- 事实表、主数据表、目标/基准表之间的连接；
- 多条件筛选、空值和状态规则；
- 分组汇总、计数、非空计数、平均值、排序和透视；
- 异常明细、结果写回、格式和表头冻结；
- 公式依赖、图表、命名区域、批注及原工作簿保真。

## 数据集位置

工作簿位于：

`tests/agent_contract/data/`（相对于项目根目录 `project/`）

任务定义位于：

`tests/agent_contract/comprehensive_benchmark_v2.json`

数据生成脚本位于：

`tests/agent_contract/generate_comprehensive_dataset.py`

## 场景组成

V2 当前包含 15 个用户任务，使用 10 个多工作表工作簿：

| 工作簿 | 业务主题 | 关键覆盖 |
|---|---|---|
| `B1_retail_operations.xlsx` | 零售订单 | 主数据连接、退货/取消、异常明细、透视和长宽变换 |
| `B2_finance_close.xlsx` | 财务关账 | 凭证审核、科目汇总、对账差异、异常工作清单 |
| `B3_supply_chain.xlsx` | 供应链 | 库存预警、供应商连接、质检和在途订单 |
| `B4_workforce.xlsx` | 人力成本 | 在职规则、预算连接、工时和绩效统计 |
| `B5_marketing_funnel.xlsx` | 营销漏斗 | CTR、转化率、ROI、目标比较、月度透视 |
| `B6_workbook_objects.xlsx` | 看板保真 | 公式依赖、错误扫描、图表、命名区域和批注 |
| `B7_workbook_admin.xlsx` | 报表管理 | 工作表复制/删除、筛选、冻结、列宽和保护 |
| `B8_data_quality.xlsx` | 数据质量 | 去重、缺失值、字段重命名、概览和频数 |
| `B9_report_publication.xlsx` | 报表发布 | 公式填充/复制、图表、格式和写回 |
| `B10_delivery_maintenance.xlsx` | 交付维护 | 范围复制、标题合并、数据验证、条件格式和超链接 |

## 设计原则

1. 一个 case 至少覆盖 3 个能力组合，不为每个原子能力重复制造孤立数据。
2. 主表与维表使用真实业务键连接，保留未匹配、空值、取消、冻结、待审核等状态。
3. Prompt 使用用户目标和验收条件描述，不暴露内部 handler 名称。
4. 结果要求包含可追溯明细或异常清单，避免只验证一个数字。
5. 同一业务主题内复用一个工作簿，不复制出多份只改变聚合函数的数据。

## 覆盖审计

当前 15 个 case 共声明 104 条能力覆盖项，去重后为 50 个能力名称；每个工作簿都包含至少一个事实表和一个辅助表。注册表中的输入路径均为相对于项目根目录的路径，生成脚本和 Excel 可读性检查应在交接包内重新执行。

旧的 26 个场景仍保留用于历史回归；V2 是后续能力扩展的主数据集。新增能力应优先在现有 V2 工作簿上增加一个真实任务，只有业务结构确实不同才新增工作簿。
