## 关键陷阱

### 陷阱1: 只写一个维度
❌ **错误**:
```json
"dimensions": [
  {"id": "region", "field": "区域", "output_name": "区域"}
]
```
这会只按区域分组，得到3行（华东/华南/华北）

✅ **正确**: 必须包含2个维度

### 陷阱2: dimensions顺序影响输出
**注意**: dimensions的顺序**会影响输出行的排序**
- `["区域", "产品类别"]` → 先按区域分组，再按类别
- `["产品类别", "区域"]` → 先按类别分组，再按区域

**本场景推荐**: 先区域后类别（符合用户自然语序）

### 陷阱3: 维度ID重复
❌ 错误：
```json
"dimensions": [
  {"id": "dim1", "field": "区域", ...},
  {"id": "dim1", "field": "产品类别", ...}  // ID重复！
]
```

✅ 正确：每个维度有唯一的ID

### 陷阱4: 遗漏acceptance
❌ 错误：
```json
"acceptance": {"required_dimensions": ["region"]}  // 只写了1个
```

✅ 正确：
```json
"acceptance": {"required_dimensions": ["region", "category"]}
```

## 多维度分组理解

**单维度（S2）**:
```
华东 → 230000
华南 → 200000
华北 → 180000
```

**双维度（S7）**:
```
华东-电子产品 → 85000
华东-家居用品 → 62000
华东-服装鞋帽 → 48000
华东-食品饮料 → 35000
华南-电子产品 → 72000
...
```

**关系**: 230000 = 85000 + 62000 + 48000 + 35000
