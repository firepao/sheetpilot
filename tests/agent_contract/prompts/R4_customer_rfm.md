# R4: 客户RFM价值分析（真实场景）

## 场景描述
电商/SaaS客户价值分析场景，按消费金额对客户分层。包含真实数据特征：30%客户只下过1单（长尾分布）。

## 测试目标
- 验证大数据量场景（6000行订单）
- 验证状态过滤（只统计已完成订单）
- 验证客户级聚合后的二次分组
- 验证RFM分析的简化版（仅F-Frequency消费金额维度）

## 输入文件
- **文件路径**: `tests/agent_contract/data/R4_customer_rfm.xlsx`
- **工作表**: `订单流水`
- **表头行**: 1
- **数据特征**: 
  - 6000行订单记录
  - 300个客户（长尾分布：30%只下过1单，少数客户有50+订单）
  - 订单状态：已完成（85%）、已取消（10%）、退款中（5%）
  - 订单日期：2026年1月-12月

## 用户需求（Prompt）

```
请分析订单流水表，按客户消费金额分组统计客户价值分布。

要求：
- 只统计已完成订单（排除已取消、退款中订单）
- 按客户分组计算总消费金额
- 将客户分为3个价值层级：
  · 高价值客户：总消费 > 10000
  · 中价值客户：总消费 3000-10000
  · 低价值客户：总消费 < 3000
- 统计各层级的客户数量和总消费金额
- 按价值层级排序（高→中→低）

输入文件: tests/agent_contract/data/R4_customer_rfm.xlsx
输出文件: <由Agent决定>
```

## 预期执行流程

1. **查询字段清单**
   ```bash
   sheetpilot-agent task-types --input tests/agent_contract/data/R4_customer_rfm.xlsx --sheet 订单流水 --header-row 1
   ```

2. **理解需求的两阶段聚合**
   - 第一阶段：按客户编号分组，计算每个客户的总消费（过滤：订单状态=已完成）
   - 第二阶段：按消费金额分段，统计各价值层级的客户数和消费金额
   
   **问题**: SheetPilot当前只支持单阶段聚合，无法表达"先按客户聚合，再按金额分段统计"
   
   **预期Agent行为**: 
   - 发现需求超出能力边界
   - 返回 `CAPABILITY_UNSUPPORTED` 或提出简化方案

3. **简化方案（如Agent提出）**
   构造Task Request：
   - 过滤条件: `订单状态 = 已完成`
   - 维度: `客户编号`
   - 指标: `sum(订单金额)` → `总消费`
   - 排序: `总消费 DESC`
   
   然后由人工或外部工具进行二次分组

4. **提交任务**
   ```bash
   sheetpilot-agent task-run --request request.json --auto-result-dir <result-dir>
   ```

5. **复核状态**
   ```bash
   sheetpilot-agent task-status --task-id <task-id>
   ```

## 预期结果

**情况A：Agent识别能力边界**
- **状态**: `CAPABILITY_UNSUPPORTED`
- **理由**: 当前不支持二阶段聚合（客户级聚合 → 价值层级分组）
- **建议**: 提供简化方案（输出客户级汇总，人工分层）

**情况B：Agent提供简化方案**
- **状态**: `RUNTIME_PASS`
- **输出**: 客户级汇总表（300行，每行1个客户）
- **人工验证**: 基于输出手工统计分层结果

### 输出数据验证（情况B简化方案）

基于生成的测试数据，预期输出300行客户汇总，统计示例：

| 价值层级 | 客户数 | 总消费 |
|---------|-------|--------|
| 高价值 | 164 | 8274736.28 |
| 中价值 | 68 | 411922.58 |
| 低价值 | 51 | 90479.69 |

**验证要点**：

- 客户总数 = 283（部分客户全部订单都被取消/退款，总消费=0）
- 长尾分布体现：高价值客户占58%（164/283），符合幂律分布
