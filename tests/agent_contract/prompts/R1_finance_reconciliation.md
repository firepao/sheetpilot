# R1: 财务科目余额表汇总（真实场景）

## 场景描述
财务会计场景，汇总科目余额表的借方/贷方金额。包含真实的数据质量问题：空值、借贷不平衡记录。

## 测试目标
- 验证空值处理能力（12%空值率）
- 验证按层级维度分组汇总
- 验证大数据量场景（600行）
- 验证财务领域语义理解

## 输入文件
- **文件路径**: `tests/agent_contract/data/R1_finance_ledger.xlsx`
- **工作表**: `科目余额表`
- **表头行**: 1
- **数据特征**: 
  - 600行记录
  - 14个一级科目（现金、银行存款、应收账款等）
  - 借方金额空值率约12%
  - 8条借贷不平衡记录（测试数据异常处理）

## 用户需求（Prompt）

```
请分析科目余额表，按一级科目汇总借方金额和贷方金额。

要求：
- 按一级科目分组
- 分别计算借方金额合计、贷方金额合计
- 空值视为0处理
- 按借方金额降序排列

输入文件: tests/agent_contract/data/R1_finance_ledger.xlsx
输出文件: <由Agent决定>
```

## 预期执行流程

1. **查询字段清单**
   ```bash
   sheetpilot-agent task-types --input tests/agent_contract/data/R1_finance_ledger.xlsx --sheet 科目余额表 --header-row 1
   ```

2. **构造Task Request**
   - 维度: `一级科目`
   - 指标: 
     - `sum(借方金额)` → `借方合计`
     - `sum(贷方金额)` → `贷方合计`
   - 排序: `借方合计 DESC`
   - 过滤: 无（包含所有记录，含异常数据）

3. **提交任务**
   ```bash
   sheetpilot-agent task-run --request request.json --auto-result-dir <result-dir>
   ```

4. **复核状态**
   ```bash
   sheetpilot-agent task-status --task-id <task-id>
   ```
