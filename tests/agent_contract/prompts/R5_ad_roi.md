# R5: 广告渠道ROI分析（真实场景）

## 场景描述
数字营销广告投放分析场景，筛选高ROI渠道。包含真实数据特征：10%负ROI广告（投放亏损）。

## 测试目标
- 验证浮点数比较过滤（ROI > 1.5）
- 验证负值数据处理（负ROI = 转化金额 < 消费金额）
- 验证派生指标验证（ROI = 转化金额 / 消费金额）
- 验证营销领域业务逻辑

## 输入文件
- **文件路径**: `tests/agent_contract/data/R5_ad_roi.xlsx`
- **工作表**: `广告投放`
- **表头行**: 1
- **数据特征**: 
  - 400行广告组记录
  - 6个投放渠道（百度搜索、抖音信息流、微信朋友圈、小红书、知乎、B站）
  - ROI分布：10%负ROI（<1.0）、20%低ROI（1.0-1.5）、70%高ROI（>1.5）
  - 投放日期：2026年1月-6月

## 用户需求（Prompt）

```
请分析广告投放数据，找出各渠道ROI表现良好的广告组。

要求：
- 只统计ROI > 1.5的广告组（表示每投入1元回报超过1.5元）
- 按投放渠道分组
- 统计各渠道的：
  1. 高ROI广告组数量
  2. 这些广告组的总ROI
- 按总ROI降序排列

输入文件: tests/agent_contract/data/R5_ad_roi.xlsx
输出文件: <由Agent决定>
```

2. **ROI分布**: 10%负ROI + 20%低ROI + 70%高ROI（真实投放效果分布）

## 关键陷阱
- ❌ **错误1**: 过滤条件写成`ROI >= 1.5`（应为`>1.5`，1.5是临界值）
- ❌ **错误2**: 未考虑负ROI的存在（假设所有ROI都>0）
- ✅ **正确**: 使用`ROI > 1.5`，自动排除负ROI和低ROI广告组

## 业务洞察
- **ROI阈值**: 1.5是常见的广告投放盈亏平衡线（扣除运营成本）
- **负ROI**: 转化金额 < 消费金额，表示广告亏损（需要优化或暂停）
- **渠道对比**: 不同渠道的高ROI广告组分布，指导预算分配
