## M3: 库存周转分析

### 数据文件
`tests/agent_contract/data/M3_inventory_turnover.xlsx`

### 用户需求
```
请统计库存状态为"正常"的商品，按仓库汇总库存金额和商品种类数。
```

### 关键要素
- **过滤**: 库存状态 = "正常"
- **维度**: 仓库
- **指标**: sum(库存金额), count.rows(商品种类数)

### 测试重点
- 库存管理场景
- count.rows统计去重后的商品种类

## M8: 项目工时统计

### 数据文件
`tests/agent_contract/data/M3_inventory_turnover.xlsx`

### 用户需求

## 数据特点

**M系列的特点**:
1. 数据量适中（100-600行）
2. 业务场景真实（电商/HR/供应链/教育/客服/项目管理）
3. 综合考察：过滤+分组+多指标
4. 从Kaggle开源数据集改造而来

**与其他系列的区别**:
- S系列: 单一功能验证，数据简单
- M系列: 业务场景组合，数据真实
- H系列: 故意设置陷阱，数据刁钻
- R系列: 复杂业务逻辑，数据脏乱
