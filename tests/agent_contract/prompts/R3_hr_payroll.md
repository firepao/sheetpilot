# R3: 人力薪资成本分析（真实场景）

## 场景描述
人力资源薪资管理场景，分析各部门的薪资成本。包含真实数据特征：迟到扣款空值表示无迟到（空值有业务语义）。

## 测试目标
- 验证空值语义理解（空值 ≠ 异常，而是"无扣款"）
- 验证多指标聚合（sum + average + count）
- 验证中等数据量场景（804行，67人×12个月）
- 验证人力领域业务逻辑

## 输入文件
- **文件路径**: `tests/agent_contract/data/R3_hr_payroll.xlsx`
- **工作表**: `薪资明细`
- **表头行**: 1
- **数据特征**: 
  - 804行薪资记录（67人 × 12个月）
  - 8个部门（研发、产品、运营、销售、市场、财务、人力、行政）
  - 迟到扣款空值率70%（表示无迟到，非数据缺失）
  - 职级：P5-P8（专业线）、M1-M2（管理线）

## 用户需求（Prompt）

```
请分析薪资明细表，按部门汇总薪资成本情况。

要求：
- 按部门分组
- 计算以下指标：
  1. 总薪资成本（实发工资总和）
  2. 平均薪资（实发工资平均值）
  3. 发薪人次（记录条数）
- 按总薪资成本降序排列

输入文件: tests/agent_contract/data/R3_hr_payroll.xlsx
输出文件: <由Agent决定>
```

## 真实性体现
1. **数据量**: 804行（67人×12个月，真实年度薪资数据量）
2. **空值语义**: 迟到扣款空值 = 无迟到，而非数据缺失（真实HR系统逻辑）

## 关键点
- ⚠️ **注意**: 迟到扣款空值不代表异常，而是正常的业务语义
- ✅ **正确理解**: 空值=无迟到，已在实发工资中体现（无需过滤或特殊处理）
- ✅ **聚合字段**: 直接sum(实发工资)，而非sum(基本工资+绩效工资-迟到扣款)
