## 使用方法

### 手工测试单个场景

1. 打开 `tests/agent_contract/prompts/R1_finance_reconciliation.md`
2. 复制"用户需求（Prompt）"章节的文本
3. 提交给Agent执行
4. 对照"预期执行流程"检查Agent行为
5. 使用"预期结果"中的Oracle值验证输出
