# 复杂 Agent Contract 测试数据集

本组数据参考交接归档中千行明细、多 Sheet、经营看板、真实公式和原生图表的复杂度生成。文件用于测试 SheetPilot 在复杂工作簿环境中定位来源 Sheet、保持原有内容并生成经营汇总的能力。

三个文件都保留标准结构：来源明细 Sheet 的第 1 行为唯一表头，适配当前 Agent-facing Task API。

## 07_complex_retail_operations.xlsx

- 业务场景：多门店零售经营。
- 来源 Sheet：`门店订单明细`。
- 数据规模：1,200 条明细、25 个字段。
- 辅助 Sheet：`门店主数据`、`经营看板`、`数据字典`。
- 工作簿对象：2 个原生图表，多组跨 Sheet 汇总公式。
- 复杂字段：区域、城市、门店、渠道、会员等级、产品品类、销售额、折扣、退款、净销售额、成本、毛利、客户编号、审核状态、取消状态、投诉标记。
- 适合测试：双维度或三维度汇总、多过滤、`sum`、`average`、`count.rows`、`count.non_empty`、输入内容保留。

建议场景：仅统计审核通过且未取消的订单，按区域和产品品类汇总净销售额、交易数量、客户编号非空数量和平均订单金额。

## 08_complex_saas_renewals.xlsx

- 业务场景：SaaS 客户续费与流失经营。
- 来源 Sheet：`客户月度经营`。
- 数据规模：960 条客户月度记录、23 个字段。
- 辅助 Sheet：`客户主数据`、`续费经营看板`、`口径说明`。
- 工作簿对象：2 个原生图表，多组跨 Sheet 汇总公式。
- 复杂字段：行业、区域、套餐、席位数、合同 MRR、折扣、实收 MRR、新增、扩容、缩减、流失、活跃用户、工单、NPS、续费状态、回款状态、风险等级。
- 适合测试：套餐集合过滤、续费状态过滤、区域与行业多维分析、收入与流失指标、目标 Sheet 冲突。

注意：工作簿已经存在 `续费经营看板`，可用于测试禁止覆盖已有目标 Sheet。

## 09_complex_dirty_logistics.xlsx

- 业务场景：物流订单质量与经营分析。
- 来源 Sheet：`物流订单流水`。
- 数据规模：1,100 条运单、24 个字段。
- 辅助 Sheet：`异常规则`、`物流运营看板`、`历史月度基线`。
- 工作簿对象：2 个原生图表，多组跨 Sheet 汇总公式。
- 数据质量特征：客户编号空值、无效记录、取消记录、待复核记录、延误、破损、异常原因和服务评分空值。
- 适合测试：按已有清洗状态过滤、多个质量条件组合、有效记录汇总、非空数量与总行数差异、多维度物流经营分析。

建议场景：只统计清洗状态有效、审核通过且未取消的订单，按运营区域和渠道汇总销售额、毛利额、运单数量、客户编号非空数量和平均实际时效。

## 设计原则

- 不覆盖原有 `01` 至 `06` 数据集。
- 明细数据使用真实数值、日期、枚举和空值类型，不把数字保存为格式化字符串。
- 看板公式使用有界范围并对中文 Sheet 名加单引号。
- 图表绑定工作簿内真实汇总区域，不使用图片代替图表。
- 工作簿包含足够的无关辅助内容，用于检查 Agent 是否错误选择来源 Sheet或破坏现有结构。
